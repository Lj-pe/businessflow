# BusinessFlow

Sistema web de gestión para pequeños comercios.

## Descripción

BusinessFlow es una plataforma web orientada a la gestión
integral de un minimarket.

El sistema permitirá gestionar:

- Usuarios y roles.
- Productos y categorías.
- Clientes.
- Proveedores.
- Inventario.
- Ventas.
- Dashboard.
- Auditoría.

## Arquitectura

El proyecto utilizará inicialmente:

- Frontend: React + Vite
- Backend: Node.js + Express
- Base de datos: MySQL
- Control de versiones: Git + GitHub
- CI/CD: Jenkins
- Contenedores: Docker
